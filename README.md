# 卡拉彼丘陪伴

让 N.E.K.O 陪你一起玩卡拉彼丘。支持语音提醒、随游戏自动启停，也可以随时在插件面板中暂停或恢复陪伴。

## 安装与连接

适用于 Windows 10/11。首次使用需要安装插件，并下载配套助手。

1. 在 N.E.K.O 插件市场安装本插件并启用。
2. 从下方任一网盘下载助手，用密码 `nekonekoneko` 完整解压到固定目录。
3. 打开插件面板，展开“助手位置与连接设置”，填写解压后的 `neko_calabiqiu_assistant` 文件夹路径。
4. 点击“启动助手”，再打开卡拉彼丘，等待面板显示就绪。

助手已包含所需运行环境，无需另行安装。通过市场安装插件后，直接在面板填写助手目录即可，无需再运行压缩包中的首次接入 CMD。

## 日常使用

- **自动陪伴**：游戏主程序启动后，助手自动在后台准备；退出游戏后自动停止。仅打开游戏启动器不会触发。
- **面板控制**：查看状态，停止、恢复或重启助手。
- **语音提醒**：切换“仅观察”和播报，暂停、恢复及试听提醒。暂停播报不会关闭助手。
- **下载与更新**：在面板中查看下载入口、解压密码和连接步骤。

手动停止助手后，本次游戏期间不会自动重新启动；点击恢复或重新打开游戏即可继续。关闭面板页面不会停止陪伴，停用插件则会停止由它启动的助手。

提醒仅供参考，请以游戏实际情况为准。

## 常见问题

**一直显示待机？** 确认已经进入游戏主程序，而不只是打开启动器。首次准备需要一些时间，可以在面板查看状态。

**移动了助手文件夹？** 先在面板停止助手，更新“助手位置与连接设置”中的目录，再重新启动。

**以前用 BAT 手动启动过？** 先关闭手动启动的助手，再从面板启动，后续即可统一使用面板控制。
